# Charming 个人博客视觉重构

## 目标

把现有博客与记忆工作台改为纯个人博客。用户已选择保留 typesafe.ai 的视觉语言，同时优先保证文章阅读体验。

## 视觉

粉色 #f386a1、深灰 #1e1e1e 与纸白 #fefefe。等宽小字用于导航、日期和编号，中文正文采用易读的系统字体。使用方形边框、细线分隔、宽松留白、少量像素与终端窗口元素。首页突出个人介绍和真实文章；阅读页限制正文宽度。顶部导航代替原侧栏，页脚采用深色区域。

所有公开页面响应式适配手机和桌面。保留深浅主题、可见焦点、跳转主要内容和减少动态效果支持。文章与导航在禁用 JavaScript 时仍可阅读。

## 内容与功能

保留 Astro Markdown 集合、全部原文和地址，尤其是 /post/about/ 的内容与 2024-11-02 日期。只显示实际文章、标签和数量，不虚构内容。保留归档、标签、Pagefind 搜索、Atom 和站点地图，以及原头像、GitHub 链接和个人文字。

移除 /memory/、记忆工作台、导入导出、IndexedDB 代码、记忆场景及其 React 依赖。已有浏览器中的历史数据不做清除操作。无需账户、数据库或第三方分析。

## 验证与发布

类型检查、生产构建和发布产物测试应通过。测试覆盖原内容与路由、记忆功能缺席、订阅、站点地图及内部链接。浏览器测试覆盖手机导航、主题、真实搜索、溢出、对比度、键盘、无 JavaScript 与减少动态效果。保留 GitHub Pages 在 main 上的自动发布工作流。
