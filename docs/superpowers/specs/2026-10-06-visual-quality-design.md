# 文字与记忆：视觉与交互品质优化

用户要求以 Awwwards、Webby Awards、FWA 获奖网站为品质参照，自检排版、留白、层级、色彩、动效、微交互、响应式与原创性并持续优化。此前已确认的个人博客与本机记忆库定位、正式发布授权和数据边界继续适用；本轮是现有设计的品质优化。

## 方向

选择暖纸感的编辑设计，围绕“记录当下，连接以后”创作纸页与记忆连线的原创主视觉。延续石墨文字和深绿标识，使首页有鲜明的构图，阅读页更专注，工作台操作清晰。相比以摄影为主的作品集，它适合目前的真实文章内容；相比沉浸式 3D 展示，它保持写作和记忆工具的快速访问。

## 设计约束

- 不改原文章、旧路径、本地存储库名/版本/字段，不新增后台服务、模型调用或第三方跟踪。
- 主文案为中文；用户数据和页面真实数量不用于虚构视觉叙事。
- 正文通常 16px 或以上；操作和说明一般 14px，细小装饰标签与正文有明确区分。使用本地系统字库，避免远程字体请求。
- 普通文字对比至少 4.5:1，大号文字和必要控件图形至少 3:1；两种主题均验收。
- 阅读正文限定行宽、舒适行距；标题和空间随屏幕连续缩放。至少验收 320、390、768、1024、1440、1920 宽度，200% 缩放和长中文输入，无横向溢出。
- 手机保留原创视觉识别，主要触摸目标至少 44px，长表单和来源文本能正常换行。
- 动效以短暂进入、纸页细节和状态反馈为主。内容默认可见，无 JS 也能读文章；尊重 prefers-reduced-motion，触摸设备不依赖悬停，键盘可完整使用。
- 动效采用 CSS 和小型浏览器模块，不新增动画框架或持续后台渲染。没有声音、光标替换、滚动劫持或加载门槛。

## 验收与停止条件

独立审查初版问题，实现后通过真实浏览器比较截图与交互，再修正有证据的问题。验收覆盖八个要求、明暗主题、不同屏宽、键盘、减少动态效果、无 JS 内容与已有记忆流程。类型、构建、22 项核心测试及原浏览器测试通过。停止条件为复审没有剩余明确缺陷或高收益改进；不宣称奖项结果或客观完美。完成后按此前发布授权更新正式站点，并验收线上版本。
